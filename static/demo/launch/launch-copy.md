# xAgent · 产品首发文案

小型技术团队可用 xAgent 把明确任务拆给独立会话：各自维护上下文与产物，用文件引用交接，再汇总给人审阅。例如首发包由 A 核对事实、B 制作离线页面与短文案，收到三个文件后检查修订，而非把事件投递当成任务完成。

开始前写清目标、材料、要求与结果，并确认当前可用能力。Tool、MCP、插件需实际配置和授权，审批依实际规则生效。当前仅支持同一用户的会话协作，完整项目级 Team 仍在规划。本首发包仅供审阅，不对外发布。

了解更多请访问官方文档：[Agent 会话指南](https://xagent.xiagaogao.com/docs/user-guide/agent-session/) · [多 Agent 会话事件协作](https://xagent.xiagaogao.com/docs/guides/multi-agent-session-event-collaboration/) · [支持的智能体功能](https://xagent.xiagaogao.com/docs/manual/capabilities/)
