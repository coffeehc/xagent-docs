xAgent `0.1.1` is available. This Server update focuses on Session recovery, model configuration, and administration, building on the team and Session foundation of 0.1.0.

This article follows the [official release notes](https://github.com/coffeehc/xagent-releases/releases/tag/v0.1.1), including the October 23, 2026 republished build, which retains version `0.1.1`. Existing users should pay particular attention to model connection-test status after upgrading.

## Automatic connection tests when saving models

Saving a model configuration now tests its connection and shows the result. New models default to a 16K maximum output, which can still be adjusted to the model's actual limits. This output budget is not the context window and does not establish a shared limit for every model.

Configurations with failed tests can still be saved, but fix the connection before using them for tasks. If an existing model disappears from selection lists after upgrading, complete its connection test in model management rather than immediately deleting and recreating it. See [model configuration](/docs/user-guide/model-config).

![Saving a model automatically tests its connection; failed configurations may be saved but need repair before task use.](/img/blog/releases/xagent-model-test-en.svg)

## Temporary failures have a visible retry wait

Temporary network or model-service failures now trigger an automatic retry wait with a countdown; users can stop the run and explicitly continue later. This distinguishes waiting from completion while retaining an explicit way to stop waiting.

See [Retry Countdown, Stop, and Continue](/docs/user-guide/agent-session#retry-stop-continue) for the exact steps.

The release also fixes inaccurate Session status after restart, continuation, or waiting. Better waiting and status displays do not guarantee recovery of an external service; verify the actual task result afterward.

## Smoother long Sessions and administration

Session lists load faster after login, and long Session pages are smoother. Approval results are clearer, while triggers gain execution history for reviewing individual scheduled runs.

See [Execution History](/docs/user-guide/trigger#execution-history) for the entry point and scheduling-outcome meanings.

Business tables consistently support resizing data columns while keeping action columns fixed. Card and icon backgrounds are unified. Lingering notices, narrow-screen table overflow, and incorrect scroll-to-bottom button display are fixed.

The republished build also fixes invalid model configurations preventing service startup and theme colors being lost when accessing the service through a domain name.

## What to check after upgrading

1. Back up configuration and data before upgrading; follow the [installation guide](/docs/getting-started/install).
2. Run `xagent version` to confirm the installed version.
3. Review model connection-test results, especially models missing from selection lists after the upgrade.
4. Use a non-sensitive task to check that Sessions start and continue, then verify the approval and trigger flows you use.

Only the Server changes in this release. Desktop clients, independent AgentPlugins, and runtime assets retain their existing versions; do not apply the Server version number to those components.

## Downloads and verification

The release page provides Linux and macOS binaries for AMD64 and ARM64, plus `SHA256SUMS`, `BINARY_SHA256SUMS`, `release.json`, and license files. Each platform package contains the executable, release information, and license files, not source code.

After downloading all files to be verified, follow the release instructions with `shasum -a 256 -c SHA256SUMS`, or `sha256sum -c SHA256SUMS` on Linux. If you download only one platform package, compare its corresponding digest instead of ignoring missing-file errors. See the [changelog](/docs/changelog) for the full release history.
