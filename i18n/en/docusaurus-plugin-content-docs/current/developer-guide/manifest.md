# Manifest

> Status: Planned.

## Who This Is For

This page is for developers who need to describe an extension package, Connector, or runtime capability declaration file.

## What It Is

A Manifest describes extension metadata and declared capabilities. No fixed fields are defined at this stage, avoiding a premature contract around an unstable schema.

## When to Use It

A Manifest is generally required when xAgent needs to discover, validate, or load an external capability.

## Planned Documentation

Future documentation should cover:

- The Manifest file name and location.
- Required and optional fields.
- Versioning and compatibility policy.
- Validation errors.
