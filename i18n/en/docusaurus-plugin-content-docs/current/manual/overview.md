## Shared Page Structure

1. The sidebar groups Workspace, Operations, Personal Settings, and administrator functions.
2. The top bar contains breadcrumbs, interface language, help, and the current account.
3. Search, filters, refresh, and create actions normally appear below the page title.
4. Tables or cards show the current resources; the actions column opens details, editing, state changes, or deletion.
5. When the sidebar is collapsed, hover over an icon for its label or use the top menu button to expand it.

To confirm what xAgent can do and which files it can process, read [Supported Agent Capabilities](/en/docs/manual/capabilities). For in-depth guidance on task writing, long-running tasks, and shortcut instructions, continue with the corresponding pages in Feature Guides.
