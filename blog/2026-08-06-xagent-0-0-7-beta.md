xAgent `0.0.7.beta` 已发布。本版本围绕文件存储与团队协作进行了较大升级，同时推出首个桌面端版本 `0.0.1`，并继续改进模型缓存、Provider 适配和图片识别能力。

本版本仍为测试版。以下内容说明本次发布的主要变化，不替代正式安装与升级指引。

{/* truncate */}

## 文件存储：从本地文件到 S3

xAgent 现在提供统一的 Local / S3 文件存储 Provider。管理员可以配置 AWS S3 或兼容 S3 的对象存储，并设置 endpoint、region、bucket、prefix、path-style 地址和凭据模式。启用前可以执行连通性以及读写校验，确认配置可用后再切换。

文件可以在 Local 与 S3 之间迁移。静态 S3 凭据会通过 KMS 加密保存，切换过程会保留配置版本和迁移进度；迁移失败时，当前有效的存储 Provider 不会被替换。

S3 运行期间会使用本地读取缓存，并校验内容大小与 SHA-256 完整性。远端暂时不可用时，xAgent 可以降级到本地存储；恢复后补传降级期间产生的内容，再切回 S3。

## 统一文件 ACL 与团队共享

本版本统一了 `workspace`、`upload` 和 `share` 三类虚拟路径的文件 ACL。新增实例级 `share` 共享目录后，管理员可以创建目录，并管理共享内容的上传、移动、重命名、下载和删除。

共享目录支持按用户或用户组设置可继承的只读 `R` 和读写 `RW` 权限。会话工具也会按照合并后的用户与会话 ACL 检查文件访问，使用户界面、Agent 和工具看到一致的可读写边界。

旧版工作区访问配置和历史共享目录会在启动或首次访问时迁移到当前结构。

## 图片识别与 OCR Agent

新增可配置的 OCR 模型角色。管理员可以选择支持视觉输入的模型，并为 OCR 单独设置模型策略。

当图片附件需要被读取为文本时，xAgent 可以生成包含可见文字、必要视觉描述和主要语言的规范 Markdown 内容。OCR 输出使用固定结构校验，模型不存在、不支持视觉输入或返回非法内容时不会保存不完整结果。

本版本的 OCR 面向图片附件；没有文本层的纯扫描 PDF 仍不在支持范围内。

## 模型上下文与缓存

用户轮次开始时的上下文和本轮选中的记忆会固定在真实用户消息上。工具循环中的实时状态追加到请求尾部，减少同一轮中稳定 Prompt 被反复改写造成的缓存失效。

会话执行上下文现在使用统一的文件 ACL 投影，让模型和工具使用同一组可读、可写边界。OpenAI、Anthropic 和 Gemini 的缓存 Token 上报语义也得到统一，能够区分 Provider 未返回缓存字段和明确返回零缓存的情况。

## Desktop Client 0.0.1

首个 xAgent Desktop Client 提供 macOS Apple Silicon 和 Windows AMD64 安装包。客户端启动后会读取公开版本目录；有适用于当前平台的新版本时，左下角会显示带红点的升级图标。

确认升级后，客户端会下载对应平台的安装包、校验 SHA-256、退出并替换程序，然后自动重启。替换失败时会保留原安装并尝试恢复启动。

## 会话界面与稳定性

本版本修复 Session Timeline 对历史字符串消息和思考块关注状态的类型处理问题，恢复 WebUI 与 Desktop 的生产构建门禁。同时补充共享目录、文件存储状态和 S3 迁移进度的管理界面与中英文文案。

## 准备升级

升级前请备份配置、数据库、工作区、共享目录和 Connector 状态。首次启用 S3 前，请先保存并测试配置，再执行 Provider 迁移；迁移完成前，当前 Provider 会保持不变。

安装与升级步骤见[开始安装](/docs/getting-started/install)和[更新日志](/docs/changelog)。
