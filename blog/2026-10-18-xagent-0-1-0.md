xAgent `0.1.0` 已正式发布。这个版本集中完善多用户智能体门户的日常工作体验：团队如何组织、工作中断后如何接续，以及身份认证和密钥在什么边界内使用。

本文依据[官方发布说明](https://github.com/coffeehc/xagent-releases/releases/tag/v0.1.0)，日期沿用发布说明中的 2026 年 10 月 18 日。免费二进制版本用于部署体验和评估，实际操作仍应以安装版本为准。

## 虚拟团队让协作关系有明确入口

0.1.0 支持创建虚拟团队，由专用经理组织成员会话树，并提供岗位复用、经理委托和所有者指导。团队资料存放在共享目录，便于围绕同一业务目标协作。

它适合需要分工和持续接续的工作：例如经理拆解资料整理任务，由不同成员分别处理，再回到团队中汇总。这里描述的是使用场景，不代表系统已经替用户完成配置、授权或结果验收。团队的具体边界见[虚拟团队指南](/docs/user-guide/virtual-teams)。

团队解散时整体归档并保留成员关系；归档分页和只读资料查看也得到改进。长期闲置会话支持自动归档，恢复与继续执行需要明确入口，不能把“资料还在”理解为“任务仍在运行”。

## 中断后的工作更容易接续

本版统一会话输入批次和运行态恢复，完善团队派工中断、协作回放和消息接续。升级 MCP SDK 后，也加固了连接复用、取消与失效恢复，并改善 HTTP 首字节等待和流式响应处理。

这些改进针对执行连续性。任务是否完成，仍要检查实际交付物、外部动作和验收条件，不能只依据一条回复或恢复后的状态提示。

## 会话和管理界面统一整理

全站接入 XUI 4.2.18，采用森林绿配色，统一列表、表格、卡片、表单和弹层。会话索引、耗时、工具调用、任务进度和审批提示得到优化，会话侧栏与管理侧栏分别调整宽度。

首屏按需加载、静态资源压缩、结构化记忆详情和异常记录管理也在本次调整范围内。审批策略修改即时保存，修改规则前应确认影响范围，修改后立即核对生效结果。

## 身份和密钥保持执行边界

Web 与桌面采用统一 Cookie 会话链路，完善初始化、退出与新文档加载的生命周期处理。密钥占位符只在允许的请求执行边界解析；文件、消息和持久化内容保留占位符，不展开真实密钥。

这不等于允许将凭据发送到任意目标。用户仍须核对任务授权、请求目的地和审批规则，不应把真实密钥写进提示词、工作区文件或截图。

## 安装、升级与验证范围

Linux 和 macOS 的 AMD64、ARM64 平台均提供二进制包。安装与升级方法见[开始安装](/docs/getting-started/install)，版本摘要见[更新日志](/docs/changelog)。升级前备份配置、数据库、工作区、Memory、Skill、Tool 包及 AgentPlugin 配置与状态。

本次只发布 Server 0.1.0；独立 AgentPlugin、桌面客户端和运行时资源包沿用各自版本。发布页包含平台包、校验清单、版本说明和授权文件；下载后应按发布页说明核对 SHA-256。

官方说明明确指出，本次没有重跑全量测试。四平台构建、包及二进制校验、安装器 mock 和公开下载完整性核对，不能等同于四个平台完整业务验收。升级后应先用非敏感材料验证会话、团队协作和实际需要的外部连接。
