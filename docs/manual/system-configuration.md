# 系统配置页面

> 版本范围：下文当前字段与行为按 2026-10-01 源码 `43d2698` 核对。较早公开二进制可能不同；遇到界面或操作差异时，先核对自己的安装版本。

系统配置页面仅管理员可见。这里的修改会影响所有用户或服务运行，应在保存前核对作用范围。

当前入口位于独立管理后台 `/admin`。本页 `v005` 图例保留供字段和旧版迁移参考；模型能力、系统超时和 Agent 角色已发生变化，以下文当前字段为准。

## 模型配置 {/* #模型配置 */}

**菜单路径：** 管理后台 &gt; 系统配置 &gt; 模型配置（`/admin/models`）

**可见范围：** 管理员

![xAgent 模型配置页面，显示 Provider、模型能力、默认状态和操作入口](/img/manual/v005/zh/admin-models.webp)

模型配置维护 Agent 可以选择的上游模型：

- 新建模型并选择 Provider 协议。
- 配置 Base URL、API Key、真实模型名、请求头和超时。
- OpenAI 兼容 Provider 可读取上游模型候选，或手工填写模型 ID；可配置上下文上限、最大输出、推理强度和兼容的思考参数。
- 聊天 Provider 声明聊天、工具调用、视觉、音频和文件能力；文生图使用独立的 OpenAI Images Provider。
- 配置模型请求并发数，测试连接后保存，并设置一个默认聊天模型；文生图模型不能设为默认聊天模型。

完整说明见 [模型配置](/docs/user-guide/model-config)。

## 系统配置 {/* #系统配置 */}

**菜单路径：** 管理后台 &gt; 系统配置 &gt; 系统配置（`/admin/config/system`）

**可见范围：** 管理员

![xAgent 系统配置页面，显示监听地址、运行目录、超时和系统邮箱](/img/manual/v005/zh/admin-system-config.webp)

系统配置维护服务级基础参数：

- 查看监听地址和只读运行根目录。
- 当前页面不再提供旧图中的 LLM 单次会话超时字段；单个模型的请求超时在模型配置中维护。
- 配置系统发信邮箱、SMTP Host、TLS 和密码。
- 保存后按页面提示判断是否需要重启服务。
- 查看当前数据库状态；SQLite 部署提供 PostgreSQL 升级流程，升级前先验证连接，并按页面确认步骤执行。

“发送测试邮件”会在存在未保存修改时先尝试保存配置，再发送测试邮件。系统发信配置与个人发信邮箱是不同范围；测试前核对发件身份和配置。

## 软件授权 {/* #软件授权 */}

**菜单路径：** 管理后台 &gt; 系统配置 &gt; 软件授权（`/admin/config/license`）

**可见范围：** 管理员

![xAgent 软件授权页面，显示设备、授权状态、范围和更新入口](/img/manual/v005/zh/admin-license.webp)

没有安装企业授权证书时，xAgent 直接使用免费版，无需申请或续期免费证书，也没有免费证书有效期。以下是当前免费版的运行容量，按整个部署统计，不是每个用户各自一份：

| 资源 | 系统总额度 | 统计口径 |
| --- | --- | --- |
| 用户 | 2 | 未停用的用户 |
| 会话 | 30 | 未删除且未归档的会话，包含所有会话种类，不只计算子会话 |
| 工作编排（WorkGroup） | 1 | 系统内的工作编排 |
| AgentPlugin VChannel | 5 | 虚拟渠道绑定，不是插件服务安装数量 |
| 定时任务 | 5 | 定时触发器，停用后仍计数；外部事件触发器不计入此项 |
| 远端 A2A | 1 | 远端 A2A 连接，与 VChannel 分开计算 |

归档会话不占用会话额度，恢复时会重新检查容量。达到上限时先检查整个部署的使用量；仅停止执行不会把一个未归档的会话移出统计，停用定时器也不会释放定时任务额度。归档与恢复步骤见[会话归档与恢复](/docs/user-guide/agent-session#archive-and-restore)。

授权控制数量权益，不设置功能白名单。实际可用能力仍取决于版本、已配置的模型与连接、账号权限和安全策略；数量额度不扩大外部系统授权。

> 当前运行容量如上；[v0.0.22.beta 附带的 EULA](https://github.com/coffeehc/xagent-releases/releases/download/v0.0.22.beta/EULA.md) 尚有旧配额表述，与此处不一致。本页不替代许可协议；许可条款问题请联系维护者确认。

安装企业版证书后，可以在这里查看设备 ID、授权编号、客户、签发时间、过期时间和数量权益。使用“更新 license”上传新的企业授权文件。

企业授权还可能设置允许的最高 xAgent 版本和 A2A 连接容量。每次升级前都应检查版本上限；A2A 额度与 AgentPlugin Channel 额度分开计算。

## 文件分享策略 {/* #文件分享策略 */}

**菜单路径：** 管理后台 &gt; 存储管理 &gt; 文件外链策略（`/admin/file-sharing`）

外链默认关闭。管理员可设为仅允许 xAgent 产物或所有受管文件，并限制默认与最长有效期、原文件下载和公开 Base URL。只有保存策略并配置可访问的 HTTPS 域名后，用户才能按策略[创建限时分享](/docs/user-guide/file-sharing)。

## Agent 角色配置 {/* #agent-角色配置 */}

**菜单路径：** 管理后台 &gt; 系统配置 &gt; Agent 角色配置（`/admin/config/agent-roles`）

**可见范围：** 管理员

![xAgent Agent 角色配置页面，显示主 Agent、编排、索引和摘要角色](/img/manual/v005/zh/admin-agent-roles.webp)

Agent 角色配置维护系统内部固定执行角色：

- 会话 Agent：正常对话、任务推进和工具循环。
- 任务能力编排：为已确认任务初始化或调整 Skill 和工具能力。
- 任务语义 Agent：判断新消息如何影响当前任务，并生成 Skill、Tool 和 Memory 召回词。
- 文生图 Agent：使用独立文生图模型和请求策略。
- OCR Agent：提取图片文字并理解非文字视觉内容。
- 摘要 Agent：为 Tool、Skill 和 Memory 生成检索摘要。
- 记忆提取 Agent：从已封存的会话历史提取可复用长期记忆。
- 上下文压缩 Agent：将历史压缩为可继续执行的结构化上下文。

当前角色可配置模型、最大并发数、适用的流式开关和 `llm_policy`。文生图角色只选择文生图模型，不显示聊天流式开关；其他角色排除文生图模型。修改后统一保存，并保留可回退配置。

旧图中的“索引 Agent”、编排补齐子 Agent 蓝图、摘要兼任上下文压缩，以及单独输出格式字段，属于旧版角色划分或界面。当前角色列表以上述八项为准，不能按旧图逐项照搬。
