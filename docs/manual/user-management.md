# 用户管理页面

用户管理页面仅管理员可见，用于控制账号状态、角色、功能级别和用户组归属。

## 用户账号

**菜单路径：** 用户管理 > 用户账号

**可见范围：** 管理员

![xAgent 用户账号页面，显示状态、角色、功能级别、用户组和操作入口](/img/manual/v005/zh/user-accounts.webp)

用户账号页用于维护控制台登录主体：

- 新建用户并设置初始身份。
- 启用或停用账号，设置普通用户或管理员角色。
- 切换简易模式与高级模式，控制高级功能菜单是否可见。
- 调整用户组、重置密码或删除不再使用的账号。

## 用户组

**菜单路径：** 用户管理 > 用户组

**可见范围：** 管理员

![xAgent 用户组页面，显示用户组类型、成员数量和操作入口](/img/manual/v005/zh/user-groups.webp)

用户组用于组织账号和表达系统内的管理范围：

- 查看内置组和自定义组。
- 新建用户组并维护成员。
- 内置组承担稳定权限语义，不应当作临时标签随意修改。
