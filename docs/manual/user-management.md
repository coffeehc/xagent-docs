# 用户管理页面

> 版本范围：下文当前字段与行为按 2026-10-01 源码 `43d2698` 核对。较早公开二进制可能不同；遇到界面或操作差异时，先核对自己的安装版本。

用户管理位于独立管理后台 `/admin`，仅管理员可见，用于维护账号状态、角色和用户组归属。普通用户访问管理入口时会回到用户端。

> 版本说明：本页 `v005` 图例保留了旧版“功能级别 / 简易与高级模式”字段。当前用户编辑表单不再提供该字段，用户菜单也不再据此隐藏功能；请不要按旧图寻找此开关。

## 用户账号 {/* #用户账号 */}

**菜单路径：** 管理后台 &gt; 用户管理 &gt; 用户账号（`/admin/users/accounts`）

**可见范围：** 管理员

![xAgent 用户账号页面，显示状态、角色、功能级别、用户组和操作入口](/img/manual/v005/zh/user-accounts.webp)

用户账号页用于维护控制台登录主体：

- 新建用户，填写登录名、显示名称、初始密码和角色。
- 启用或停用账号，设置普通用户或管理员角色。
- 区分角色与功能入口：`user` 使用用户端，`admin` 还可进入管理后台；当前没有通过简易 / 高级模式切换菜单的操作。
- 调整用户组、重置密码或删除不再使用的账号。

建议顺序：先新建账号并确认角色和用户组，再验证用户端可访问范围。临时限制访问优先使用停用；重置密码和删除账号前，核对账号身份与操作确认内容，避免误操作同名用户。

## 用户组 {/* #用户组 */}

**菜单路径：** 管理后台 &gt; 用户管理 &gt; 用户组（`/admin/users/groups`）

**可见范围：** 管理员

![xAgent 用户组页面，显示用户组类型、成员数量和操作入口](/img/manual/v005/zh/user-groups.webp)

用户组用于组织账号和表达系统内的管理范围：

- 查看内置组和自定义组。
- 新建或编辑用户组的名称与说明；成员归属在用户账号编辑表单中维护。
- 内置组承担稳定权限语义，不应当作临时标签随意修改。
- 内置组不提供删除入口；自定义组可在核对影响后删除。
