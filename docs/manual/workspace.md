# 工作台页面

工作台是所有用户进入 xAgent 后最常用的区域。普通用户默认可以看到仪表板、Agent 会话和工作区文件；会话列表需要管理员开启高级模式。

## 简洁模式与高级模式

xAgent 用两种菜单模式平衡易用性和可配置性。简洁模式只保留完成日常任务所需的入口，适合大多数用户，尤其适合刚开始接触 AI 的用户；菜单更少，进入后可以直接提交任务，不会被过多设置干扰。

高级模式在简洁模式的基础上增加编排和能力管理入口，适合需要查找历史会话、配置自动化任务、管理智能体、Skill、Tool/MCP 或个人审批策略的用户。管理员可以为每个账号单独开启高级模式；模式只影响菜单显示，不会改变账号已有的权限。

| 模式 | 菜单差别 | 建议 |
| --- | --- | --- |
| 简洁模式 | 仪表板、Agent 会话、工作区文件、审批、我的连接、密钥管理、账号管理 | 默认模式，适合直接开始工作 |
| 高级模式 | 在简洁模式基础上增加会话列表、触发器管理、智能体管理、Skill 管理、我的工具、我的 MCP、个人审批策略 | 需要更多管理和编排能力时启用 |

## 仪表板

**菜单路径：** 工作台 > 仪表板

**可见范围：** 所有用户

![xAgent 仪表板页面，显示 Token、模型调用、工具调用和会话状态](/img/home/v005/xagent-dashboard-zh.webp)

仪表板用于快速判断当前使用量和会话运行状态：

- 顶部指标区汇总输入、缓存、输出和总 Token，以及模型与工具调用次数。
- 时间范围可以在今日、本周、本月、本年和自定义日期之间切换。
- 趋势图用于比较 Token 与调用次数的变化。
- 会话面板显示执行状态、审批阻塞和最近更新时间，可进入具体会话。

## Agent 会话

**菜单路径：** 工作台 > Agent会话

**可见范围：** 所有用户

![xAgent Agent 会话页面，显示会话列表、时间线、上下文状态和输入区](/img/home/v005/xagent-task-session-zh.webp)

Agent 会话是提交任务和持续协作的主页面：

- 左侧管理最近会话并新建会话；主会话与子会话会分别显示状态。
- 中间时间线展示消息、工具调用、审批请求、文件和任务结果。
- 顶部显示上下文、Token、工具调用可见性和高级设置。
- 底部输入区支持文本、附件和语音输入；任务运行中可以继续补充要求。

完整操作见 [Agent 会话](/docs/user-guide/agent-session) 和 [快捷指令](/docs/user-guide/shortcut-instructions)。

## 工作区文件

**菜单路径：** 工作台 > 工作区文件

**可见范围：** 所有用户

![xAgent 工作区文件页面，显示业务空间、工作组材料、上传文件和 Agent 会话目录](/img/manual/v005/zh/workspace-files.webp)

工作区文件用于查看用户可访问的材料与产物：

- 左侧目录树区分业务空间、工作组材料、上传文件和 Agent 会话文件。
- 选择文件后在右侧预览文本、图片、PDF、表格或 HTML 产物。
- 工具栏可以上传、刷新、下载或复制可读路径。
- 页面只展示当前用户有权访问的工作区投影，不等同于宿主机任意目录。

完整操作见 [工作区文件](/docs/user-guide/workspace)。

## 会话列表

**菜单路径：** 工作台 > 会话列表

**可见范围：** 开启高级模式的用户

![xAgent 会话列表页面，显示会话状态、类型、更新时间、目标和操作入口](/img/manual/v005/zh/session-list.webp)

会话列表提供比 Agent 会话左栏更完整的管理视图：

- 支持按会话名称和目标类型搜索。
- 列表显示会话状态、主会话或子会话类型、更新时间和目标摘要。
- 操作列可以进入会话；具备权限时可以删除不再需要的子会话。
- 会话列表用于管理，不替代会话时间线中的任务执行过程。
