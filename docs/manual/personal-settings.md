# 个人设置页面

个人设置只影响当前账号。全局策略和系统配置仍由管理员页面负责。

## 账号管理

**菜单路径：** 个人设置 > 账号管理

**可见范围：** 所有用户

![xAgent 账号管理页面，显示基本信息、界面设置、密码、默认交互和邮箱管理](/img/manual/v005/zh/account-management.webp)

账号管理集中维护当前用户资料与默认体验：

- 修改用户名和显示名称。
- 选择亮色、暗色或跟随系统，以及紧凑、标准或宽松密度。
- 设置默认回复语言、详细程度和工作流风格。
- 修改登录密码并管理个人发信邮箱。

## 个人审批策略

**菜单路径：** 个人设置 > 个人审批策略

**可见范围：** 开启高级模式的用户

![xAgent 个人审批策略页面，显示风险等级和用户覆盖规则](/img/manual/v005/zh/personal-approval-policy.webp)

个人审批策略用于在管理员允许的范围内调整当前用户的确认偏好：

- 查看不同风险等级的默认处理方式。
- 为具体工具或动作配置更严格的用户规则。
- 个人策略不能放宽管理员定义的强制审批边界。

完整说明见 [审批策略](/docs/user-guide/approval-policy)。
