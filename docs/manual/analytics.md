# 统计分析页面

> 版本范围：下文当前字段与行为按 2026-10-01 源码 `43d2698` 核对。较早公开二进制可能不同；遇到界面或操作差异时，先核对自己的安装版本。

xAgent 区分个人用量与管理员统计：普通用户可查看自己的模型和工具用量；管理员在独立管理后台查看组织级用量与服务运行状态。统计用于容量和成本判断，不等同于账单结算记录。

## 个人用量统计 {/* #个人用量统计 */}

**菜单路径：** 工作台 &gt; 用量统计（`/app/dashboard`）

**可见范围：** 当前登录用户

- 按时间范围查看自己的输入、缓存、输出和总 Token。
- 查看自己的模型调用、工具调用和模型用量明细。
- 个人页面不展示其他用户的用量；管理员进入 `/app` 时也使用个人范围。

时间范围支持今天、本周、本月、本年和自定义日期。遇到读取失败先重试或刷新；没有加载到数据不能等同于零用量。

## 管理员 Token 统计 {/* #管理员-token-统计 */}

**菜单路径：** 管理后台 &gt; 统计分析 &gt; 运行统计（`/admin/users/token-usage`）

当前菜单名为“运行统计”，包含原 Token 统计和管理员运行概览。

**可见范围：** 管理员

![xAgent Token 统计页面，显示总量、趋势、模型和用户维度](/img/manual/v005/zh/token-usage.webp)

Token 统计用于分析模型使用量：

- 按时间范围查看输入、缓存、输出和总 Token。
- 查看模型调用与工具调用趋势。
- 在模型和用户维度定位主要消耗来源。
- 运行概览展示用户、会话、AgentPlugin、触发器、MCP 和 A2A 等数量及状态，便于结合用量排查。
- 统计用于容量和成本判断，不等同于账单结算记录。

## 系统监控 {/* #系统监控 */}

**菜单路径：** 管理后台 &gt; 统计分析 &gt; 系统监控（`/admin/system-monitoring`）

**可见范围：** 管理员

![xAgent 系统监控页面，显示资源使用、服务状态和运行指标](/img/manual/v005/zh/system-monitoring.webp)

系统监控用于检查服务健康与资源压力：

- 查看 CPU、内存、磁盘、系统负载、网络和 xAgent 运行时指标。
- 检查 Connector 健康和服务可用性；模型、工具调用趋势应到“运行统计”查看。
- 结合服务日志判断异常是瞬时波动还是持续故障。

## 错误记录 {/* #错误记录 */}

**菜单路径：** 管理后台 &gt; 统计分析 &gt; 错误记录（`/admin/platform-incidents`）

**可见范围：** 管理员

- 查看错误采集是否启用，按来源、性质、严重程度和关键词定位记录。
- 列表使用服务端查询和分页；打开详情查看错误样本、发生时间及相关会话或工具标识。
- 删除单条或清空前先保留排查需要的信息；清理记录不会修复产生错误的原因。

建议排查顺序：先查看错误记录中的具体错误和关联对象，再检查系统监控中的资源压力，最后结合运行统计和原会话确认影响范围。
