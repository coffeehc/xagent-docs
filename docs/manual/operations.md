# 运行治理页面

> 版本范围：基础页面字段按 2026-10-01 源码 `43d2698` 核对；本文标注的 0.0.22 新行为依据 [v0.0.22.beta 发布说明](https://github.com/coffeehc/xagent-releases/releases/tag/v0.0.22.beta)。遇到界面或操作差异时，先核对自己的安装版本。

运行治理负责当前登录用户的任务控制和能力配置，入口位于用户端 `/app`。当前菜单不再按“简易 / 高级模式”隐藏本页功能；具体资源和可执行动作仍受账号权限、服务就绪状态及审批策略约束。管理员的全局配置位于独立的 `/admin` 后台。

> 图例说明：本页保留的 `v005` 截图用于说明字段和操作，部分旧菜单名称与布局已变化。下文菜单路径按当前版本标注。

## 审批 {/* #审批 */}

**菜单路径：** 运行治理 &gt; 审批（`/app/approvals`）

**可见范围：** 所有用户

![xAgent Agent 会话中的高风险 Tool 审批卡片，显示风险等级、资源范围和同意操作](/img/manual/v005/zh/agent-session.webp)

审批页集中处理任务中的敏感动作：

- 查看待处理、已通过和已拒绝的请求。
- 核对发起会话、工具、风险等级、参数摘要和原因。
- 通过或拒绝后，结果会返回原会话继续执行。
- 会话进入审批等待时，系统会尝试向当前用户全部可用的 IM 消息通道发送通知，也包括 Web 发起的任务。按通知中的 `@{approval:审批ID} 同意` 或 `@{approval:审批ID} 不同意` 回复；同一审批最先被接受的有效意见生效。

## 触发器管理 {/* #触发器管理 */}

**菜单路径：** 运行治理 &gt; 触发器（`/app/triggers`）

**可见范围：** 当前登录用户

![xAgent 触发器管理页面，显示状态、类型、策略、下次触发时间和操作入口](/img/manual/v005/zh/triggers.webp)

触发器用于按时间或事件自动发起任务：

- 搜索并按类型筛选触发器。
- 查看启用状态、调度策略、下次触发时间和稳定 Key。
- 支持新建、手动触发、启停、编辑和删除。
- 详情可核对目标会话、激活上下文、最近成功提交次数和最近错误；触发成功只表示消息已投递，不代表任务已完成。

完整操作见 [触发器管理](/docs/user-guide/trigger)。

## 智能体管理 {/* #智能体管理 */}

**菜单路径：** 运行治理 &gt; 智能体（`/app/agent-definitions`）

**可见范围：** 当前登录用户

![xAgent 用户侧智能体管理页面，显示可用智能体及其来源](/img/home/v005/xagent-agent-management-zh.webp)

用户侧智能体页面用于选择和维护个人可用的任务入口：

- 查看内置、公共和个人智能体。
- 搜索名称、提示词、Skill、Tool 或密钥依赖。
- 新建个人智能体，或查看公共智能体定义。

完整概念见 [智能体管理](/docs/user-guide/agent-management)。

## Skill 管理 {/* #skill-管理 */}

**菜单路径：** 运行治理 &gt; 技能（`/app/skills`）

**可见范围：** 当前登录用户

Skill 管理用于复用任务方法和维护个人 Skill：

- 搜索 Skill，查看资源文件，并在会话中按需加载。
- 创建、校验、编辑和发布个人 Skill。

完整操作见 [Skill 管理](/docs/user-guide/skill)。

## 我的工具 {/* #我的工具 */}

**菜单路径：** 运行治理 &gt; 工具（`/app/tools`）

**可见范围：** 当前登录用户

![xAgent 我的工具页面，显示工具来源、风险、就绪状态和操作入口](/img/manual/v005/zh/tools.webp)

我的工具汇总当前账号可以使用的原生、MCP 和 AgentPlugin 工具：

- 按名称、来源、风险和就绪状态搜索或筛选。
- 查看工具描述、参数、审批要求和不可用原因。
- 工具是否可调用同时受系统状态、账号范围和审批策略约束。

完整说明见 [Tool 管理](/docs/user-guide/tool)。

## 插件连接 {/* #插件连接 */}

**菜单路径：** 运行治理 &gt; 我的插件（`/app/plugin-connections`）

**可见范围：** 所有用户

![xAgent 我的连接页面，显示 Connector 通道、认证状态和专属会话](/img/manual/v005/zh/connections.webp)

插件连接用于把个人外部账号绑定到已安装的 AgentPlugin：

- 查看通道连接状态、认证状态、绑定目标和专属会话。
- 创建连接并完成二维码、Bot 或应用授权流程。

完整操作见 [AgentPlugin](/docs/user-guide/connector)。

## 环境变量（原密钥管理） {/* #密钥管理 */}

**入口说明：** 以下截图和 `/app/secrets` 为旧版密钥入口参考；`v0.0.22.beta` 已将密钥管理升级为环境变量，请以已安装版本的实际菜单为准。

**可见范围：** 所有用户

![xAgent 密钥管理页面，显示密钥名称、值预览、用途和更新时间](/img/manual/v005/zh/secrets.webp)

环境变量可以保存凭据，也可以保存非敏感配置。创建前先区分两种模式：

| 模式 | 用途与读取边界 |
| --- | --- |
| 加密 | 用于密码、访问令牌等敏感值；向模型只暴露占位符 |
| 非加密 | 用于可按需读取的普通文本配置；不要把它当成保密存储 |

加密模式创建后不可更改。填写清楚名称、说明和使用注意事项；保存非加密变量时，名称含 `KEY`、`TOKEN` 等敏感标识会触发确认提醒。提醒不能代替对内容敏感性的判断。升级时，既有密钥迁移为加密环境变量。

不要把真实凭据写进提示词、工作区文件或截图。环境变量的模式和读取边界依据 [v0.0.22.beta 发布说明](https://github.com/coffeehc/xagent-releases/releases/tag/v0.0.22.beta)；旧截图不展示这些新增字段。
