# 运行治理页面

运行治理负责用户侧的任务控制和能力配置。审批、连接和密钥对所有用户可见；其余页面需要管理员为账号开启高级模式。

## 审批

**菜单路径：** 运行治理 > 审批

**可见范围：** 所有用户

![xAgent 审批页面，显示待处理和历史审批](/img/manual/v005/zh/approvals.webp)

审批页集中处理任务中的敏感动作：

- 查看待处理、已通过和已拒绝的请求。
- 核对发起会话、工具、风险等级、参数摘要和原因。
- 通过或拒绝后，结果会返回原会话继续执行。
- 所有已连接的 IM 都会同步收到审批通知，可以直接在手机上完成审批。

## 触发器管理

**菜单路径：** 运行治理 > 触发器管理

**可见范围：** 开启高级模式的用户

![xAgent 触发器管理页面，显示状态、类型、策略、下次触发时间和操作入口](/img/manual/v005/zh/triggers.webp)

触发器用于按时间或事件自动发起任务：

- 搜索并按类型筛选触发器。
- 查看启用状态、调度策略、下次触发时间和稳定 Key。
- 支持新建、手动触发、启停、编辑和删除。

完整操作见 [触发器管理](/docs/user-guide/trigger)。

## 智能体管理

**菜单路径：** 运行治理 > 智能体管理

**可见范围：** 开启高级模式的用户

![xAgent 用户侧智能体管理页面，显示可用智能体及其来源](/img/home/v005/xagent-agent-management-zh.webp)

用户侧智能体页面用于选择和维护个人可用的任务入口：

- 查看内置、公共和个人智能体。
- 搜索名称、提示词、Skill、Tool 或密钥依赖。
- 新建个人智能体，或查看公共智能体定义。

完整概念见 [智能体管理](/docs/user-guide/agent-management)。

## Skill 管理

**菜单路径：** 运行治理 > Skill 管理

**可见范围：** 开启高级模式的用户

![xAgent 用户侧 Skill 管理页面，显示 Skill 来源、状态和操作入口](/img/home/v005/xagent-skill-tool-zh.webp)

Skill 管理用于复用任务方法和维护个人 Skill：

- 查看内置、公共和个人 Skill 的摘要与状态。
- 搜索 Skill，查看资源文件，并在会话中按需加载。
- 创建、校验、编辑和发布个人 Skill。

完整操作见 [Skill 管理](/docs/user-guide/skill)。

## 我的工具

**菜单路径：** 运行治理 > 我的工具

**可见范围：** 开启高级模式的用户

![xAgent 我的工具页面，显示工具来源、风险、就绪状态和操作入口](/img/manual/v005/zh/tools.webp)

我的工具汇总当前账号可以使用的原生、MCP 和 Connector 工具：

- 按名称、来源、风险和就绪状态搜索或筛选。
- 查看工具描述、参数、审批要求和不可用原因。
- 工具是否可调用同时受系统状态、账号范围和审批策略约束。

完整说明见 [Tool 管理](/docs/user-guide/tool)。

## 我的 MCP

**菜单路径：** 运行治理 > 我的 MCP

**可见范围：** 开启高级模式的用户

![xAgent 我的 MCP 页面，显示个人可用 MCP 服务和连接状态](/img/manual/v005/zh/mcp.webp)

我的 MCP 用于查看和管理当前账号接入的 MCP 服务：

- 查看服务状态、协议、工具数量和来源。
- 新建或编辑用户范围的 MCP 连接。
- 服务异常时先检查地址、认证和管理员侧全局配置。

## 我的连接

**菜单路径：** 运行治理 > 我的连接

**可见范围：** 所有用户

![xAgent 我的连接页面，显示 Connector 通道、认证状态和专属会话](/img/manual/v005/zh/connections.webp)

我的连接用于把个人外部账号绑定到已安装的 Connector：

- 查看通道连接状态、认证状态、绑定目标和专属会话。
- 创建连接并完成二维码、Bot 或应用授权流程。
- 进入专属会话，或在连接失效时重新认证和重新打开通道。

完整操作见 [连接器](/docs/user-guide/connector)。

## 密钥管理

**菜单路径：** 运行治理 > 密钥管理

**可见范围：** 所有用户

![xAgent 密钥管理页面，显示密钥名称、值预览、用途和更新时间](/img/manual/v005/zh/secrets.webp)

密钥管理用于保存任务和外部服务需要的敏感值：

- 新建稳定的 Secret Key，并填写用途说明。
- 页面只显示掩码预览，不回显完整密钥。
- Skill、Tool 和配置通过密钥占位符引用，不应把真实值写进提示词或工作区文件。
