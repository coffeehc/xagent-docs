# 什么是连接器

## 它解决什么问题

企业通常已经有自己的 CRM、ERP、OA、客服、知识库等系统。每套系统里都有现成的员工账号、数据权限和操作规则。接入 AI 时，真正困难的往往不是“让 AI 回答一个问题”，而是下面这些事情：

- 不希望为了接入 xAgent，重新改造每一套内部系统。
- 不希望给 xAgent 一个所有人共用、权限过大的系统账号。
- 希望员工继续使用自己原来的账号和权限。这个员工原来能看什么、能做什么，接入 xAgent 后仍然保持一致。
- 不仅要从内部系统读取信息，还要在用户确认后把回复、文件或操作结果写回原系统。

**连接器就是用来解决这些问题的。**它在不改动企业内部系统原有业务逻辑的前提下，使用系统已有的登录、授权和接口方式完成接入。用户把自己在内部系统中的账号连接到 xAgent 后，xAgent 使用的是这个用户原有的身份和权限，不会凭空获得更多权限。

可以把它理解成：连接器把用户在原系统中的身份和权限“挂载”到 xAgent 上，而不是给 xAgent 单独开一个权限更大的公共账号。

这条连接不是单向读取，而是双向通信：内部系统的消息、文件和数据可以进入 xAgent，经过用户确认的回复、文件和操作也可以通过连接器回到原来的系统。

## 连接器是什么

可以把连接器理解成 xAgent 和企业现有系统之间的一条双向通道：

```text
企业内部系统（原有账号和权限）  <->  连接器  <->  xAgent
```

连接器不只是转发数据。根据内部系统提供的能力，它还可以负责账号登录、保持连接、接收消息和文件、把结果写回去，并告诉 xAgent 当前可以使用哪些能力。

不同连接器支持的功能可能不同。例如，有的连接器接入 CRM 或知识库，有的接入微信、飞书等消息系统；有的需要扫码登录，有的使用网页授权。实际能力以连接器页面中的说明为准。

## 它能做什么

连接器通常可以帮助你：

- 连接或绑定自己在企业系统中的原有账号。
- 让 xAgent 在这个账号原有的权限范围内读取数据和使用功能。
- 把企业系统中的消息、文件、数据和事件送进 xAgent。
- 把 xAgent 的回复、文件或经过确认的操作结果写回原来的系统。
- 让 xAgent 使用该连接器提供的额外能力。
- 显示连接是否正常，方便发现掉线或授权失效。

例如，一名员工原来只能查看 CRM 中自己负责的客户。绑定自己的 CRM 账号后，他可以让 xAgent 帮忙查询和整理这些客户的信息，但不能因此看到其他员工负责的客户。需要更新客户记录时，经过确认的结果也可以通过同一个连接器写回 CRM。

## 它和 MCP 有什么区别

用大白话说：

- **连接器像“门口”**：外部的人、账号、消息和事件可以从这里进入 xAgent，处理结果也可以从这里送回去。
- **MCP 像“工具箱”**：xAgent 已经在处理任务时，需要查询资料或调用某项外部能力，就从工具箱里取出对应工具。

| 对比 | 连接器 | MCP |
| --- | --- | --- |
| 主要连接什么 | 用户在现有系统中的账号、权限、消息和事件 | 可以被 xAgent 调用的工具和服务 |
| 通常由谁开始 | 外部消息或事件可以主动发起任务 | xAgent 在任务中按需调用 |
| 主要解决什么 | 保留原有用户身份和权限，并与原系统双向通信 | 为任务提供一个可以按需调用的外部能力 |
| 常见例子 | 使用员工自己的 CRM 权限读取资料，再把确认后的结果写回 CRM | xAgent 调用一个查询知识库的工具 |

判断时可以先问自己一句：

- “我想把用户在现有系统中的账号和权限接入 xAgent，并且能读也能写回”——通常需要连接器。
- “我想让 xAgent 做任务时调用一个外部工具”——通常需要 MCP。

## 两者可以一起使用

连接器和 MCP 不是二选一，它们经常一起完成一件事。例如：

1. 员工让 xAgent 分析自己负责的客户。
2. CRM 连接器使用这名员工的账号和权限读取客户资料。
3. xAgent 通过 MCP 调用市场数据或其他分析工具。
4. xAgent 整理出客户跟进建议。
5. 员工确认后，CRM 连接器把跟进记录写回 CRM。

在这个过程中，连接器负责“以谁的身份访问企业系统、可以读写哪些数据”，MCP 负责“处理任务时调用哪些外部工具”。

## 什么时候选择连接器

遇到下面这些需求时，优先考虑连接器：

- 希望在不改造原有业务系统的情况下，把它接入 xAgent。
- 希望每个用户继续使用自己在原系统中的账号和权限。
- 既要读取原系统中的数据，也要把经过确认的结果写回去。
- 希望原系统中的消息或事件可以触发 xAgent 处理。

如果只是希望 xAgent 在任务中查询或操作某个外部服务，一般先考虑 MCP。

## 怎么开始使用

1. 管理员先在“连接器”中添加并配置可用的连接器。
2. 用户打开“我的连接”，按页面提示完成扫码、授权或账号绑定。
3. 连接成功后，就可以从对应的外部系统发起任务，或在 xAgent 会话中使用该连接器提供的能力。

连接成功不等于获得了无限权限。连接器仍然使用外部账号原有的权限；发送消息、修改数据等敏感操作，也可能需要用户确认。

不要把密码、访问令牌或验证码直接发到会话里。需要登录时，请使用连接器页面提供的授权方式。
