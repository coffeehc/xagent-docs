## Issue 与讨论的区别

讨论区不是 Bug 跟踪器。发现可复现问题，或下载包、安装、升级出现故障时，请提交 [Issue](https://github.com/coffeehc/xagent-releases/issues/new)。

提交 Issue 时请包含：

- 使用的 xAgent 版本、操作系统和部署方式；
- 实际发生的现象与预期结果；
- 可安全公开的日志、截图和复现步骤；
- 已尝试的排查方式。

功能想法、场景讨论和 Skill 改进不需要先写成 Issue，优先在 Discussions 中交流。确认有明确实现边界后，维护者会再决定是否转为 Issue 跟踪。

## 讨论时请注意

- 不要发布真实密钥、token、验证码、客户数据、内部地址或未脱敏日志。
- 禁止发布色情、暴力、仇恨、骚扰、政治煽动、违法交易、垃圾营销，以及与 xAgent 无关的内容。
- 分享案例时说明目标、输入材料类型、关键约束和结果标准，比只列功能名更有帮助。
- Skill 改进请聚焦通用任务流程、输入要求、输出标准、质量检查和安全边界；不要把特定第三方 MCP、私有服务或个人账号作为默认依赖。
- 讨论区面向真实使用，欢迎提出限制和失败经验，它们同样能帮助改进产品。

维护者可以删除不符合上述要求的内容、锁定失控讨论，或限制持续违规账号的互动。
