# xAgent 工作区文件：材料、结果与下载产物

工作区文件用于完成“上传材料、引用材料、检查结果、下载或继续处理”的闭环。先确认文件属于当前任务，再查看内容和交付格式。

## 从材料到交付 {/* #从材料到交付 */}

1. [上传文件](#%E4%B8%8A%E4%BC%A0%E6%96%87%E4%BB%B6)，等待上传完成后说明要处理的范围。
2. [引用文件](#%E5%BC%95%E7%94%A8%E6%96%87%E4%BB%B6)，使用界面里的文件名或可读路径。
3. [查看结果](#%E6%9F%A5%E7%9C%8B%E7%BB%93%E6%9E%9C)，确认会话提到的文件确实已保存。
4. [预览和下载](#%E9%A2%84%E8%A7%88%E5%92%8C%E4%B8%8B%E8%BD%BD)，检查内容、图表、文字和敏感信息。
5. 需要继续修改时，[引用已有产物](#%E7%BB%A7%E7%BB%AD%E4%BD%BF%E7%94%A8%E5%B7%B2%E6%9C%89%E4%BA%A7%E7%89%A9)，明确这次修改的目标。

上传、模型读取和界面预览各有不同边界。Office 文本提取不等于原版式渲染；纯扫描 PDF 也不能因为能预览就视为可提取正文。格式与限制见[支持的智能体功能](/docs/manual/capabilities)。

## 适用对象 {/* #适用对象 */}

本文适合需要上传文件、查看产物、预览报告或复用任务材料的用户。

## 这是什么 {/* #这是什么 */}

工作区是 xAgent 保存任务材料和结果的地方。你上传的文件、任务生成的 Markdown、CSV、HTML 报告和中间结果，通常都会出现在工作区文件中。

xAgent 会按用户和任务范围隔离文件。需要运行外部命令时，Execution Lease 会生成最小文件视图，再由 ProcessSandbox 只挂载本次任务获得授权的路径。日常使用时，只需要关注页面里能看到的文件。

在 `v0.0.20.beta` 中，进程工具生成的文件会正确提交到工作区，会话草稿在沙箱内保持可见；仍只允许访问当前任务授权的范围。

## 什么时候使用 {/* #什么时候使用 */}

下面情况需要关注工作区：

- 任务需要读取文件、表格、PDF、文档或图片。
- 任务要生成可下载的文件。
- 需要预览 HTML 报告或其他结果。
- 需要在后续会话中继续引用已有材料。
- 需要确认某个结果是否已经保存。

## 基本用法 {/* #基本用法 */}

### 上传文件 {/* #上传文件 */}

1. 在 Agent会话 或工作区相关入口上传文件。
2. 等待文件上传完成。
3. 在任务里说明要处理哪个文件。
4. 如果文件很多，说明处理范围和优先级。

示例：

```text
请阅读我刚上传的三份 PDF，只整理和“采购流程”有关的内容，输出摘要和原文证据。
```

### 引用文件 {/* #引用文件 */}

引用文件时，优先使用页面中能看到的文件名或路径。例如：

```text
请处理工作区里的 customer_feedback.xlsx，找出反馈最多的 5 类问题。
```

不要写本机桌面路径，也不要写服务器内部路径。xAgent 只能处理当前工作区和授权范围内的文件。

### 查看结果 {/* #查看结果 */}

任务完成后，先看会话回复。如果回复中提到已生成文件，再进入工作区文件查看。

常见结果包括：

| 文件类型 | 常见用途 |
| --- | --- |
| Markdown | 总结、清单、会议纪要、轻量报告 |
| CSV / Excel | 表格结果、结构化数据、统计明细 |
| HTML | 带样式、图表或完整排版的报告 |
| PDF | 需要固定版式或外发的报告 |
| 图片 | 图表、截图、视觉结果 |

### 预览和下载 {/* #预览和下载 */}

如果结果是 HTML、Markdown 或图片，优先使用预览入口确认内容。如果需要转发、存档或继续处理，再下载文件。

管理员开启文件外链策略后，也可从预览、会话文件或工作区文件菜单[创建限时分享](/docs/user-guide/file-sharing)。默认不允许公开分享；访客预览附带动态水印，原文件下载需要单独允许。

预览时重点检查：

- 标题和内容是否正确。
- 表格或图表是否完整。
- 中文是否显示正常。
- 是否包含不应公开的敏感信息。
- 文件是否来自当前任务，而不是旧结果。

### 继续使用已有产物 {/* #继续使用已有产物 */}

工作区文件可以继续作为下一步任务材料。例如：

```text
请基于刚生成的 summary.md，再整理一版给管理层看的 5 分钟汇报提纲。
```

如果文件名相似，建议明确说明文件名，避免使用错材料。

## 文件安全 {/* #文件安全 */}

使用工作区时注意：

- 不要上传不该进入系统的敏感文件。
- 外发前检查报告里是否包含个人信息、密钥、内部地址或客户数据。
- 删除、覆盖、发送等动作可能需要审批。
- 需要长期使用的材料，应使用稳定文件名和目录。
- 临时文件不一定适合作为正式交付结果。
