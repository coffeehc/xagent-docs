# xAgent 长期记忆：跨会话保留偏好与决策

> 状态：实验性能力，接口可能变化。

## 适用对象 {/* #适用对象 */}

本文适合希望 xAgent 跨会话保留稳定偏好、已确认决策或长期背景的用户。

## 这是什么 {/* #这是什么 */}

长期记忆用于在同一用户的多个会话之间复用稳定信息。当前实现包含用户显式要求、用户直接管理和后台历史提炼三种入口。它是跨会话的背景上下文，不等同于会话历史、上下文压缩，也不会把所有聊天自动变成长期事实。

本文按 2026-10-01 主分支 `43d2698` 核对。旧版实验性实现曾仅提供显式登记；后台提炼和管理能力应以部署版本为准，不能据此假定旧实例已有相同行为。

## 什么时候使用 {/* #什么时候使用 */}

当某些信息会持续影响后续任务时，可以明确让 xAgent 记住，例如：

- 稳定的输出语言、格式和协作偏好。
- 项目的长期背景。
- 已确认的关键决策。
- 不能越过的业务边界或协作规则。

## 基本用法 {/* #基本用法 */}

### 明确要求记住 {/* #明确要求记住 */}

在当前消息中直接说明要跨会话保留的事实：

```text
请记住：这个项目的周报以后默认使用中文，并包含风险和下一步。
```

通过会话调用显式记忆入口时，当前用户消息必须明确授权跨会话创建、补充、纠正或归档记忆。登记成功表示后台写入任务已经排队，并不等于写入已完成。长期规则和禁止边界只能通过显式授权进入，不能由后台提炼推断产生。

### 召回以前的信息 {/* #召回以前的信息 */}

需要使用以前的偏好或决策时，可以直接说明主题：

```text
请查一下我之前关于这个项目周报格式的约定，再生成本周周报。
```

xAgent 会在相关记忆可能实质影响当前任务时查询当前用户的长期记忆。查询结果仍会结合来源、更新时间、置信度和当前事实判断，不能替代对实时外部信息的核验。

### 修改当前要求 {/* #修改当前要求 */}

如果当前要求与旧记忆冲突，直接给出新的明确要求：

```text
这次周报改用英文，只对本次任务生效。
```

当前用户输入、工具结果、权限和系统规则优先于旧记忆。明确限定本次任务的临时调整不应沉淀为长期记忆；需要长期修改时，应再次明确要求记住新的规则，并核对最终保存内容。

### 在“我的记忆”中管理 {/* #在我的记忆中管理 */}

部署版本提供“我的记忆”入口时，可以查看当前用户的记忆，并直接新增或删除条目。手工新增保存用户提交的原文作为来源证据，并同步写入事实库；会话中的“记住”则是后台登记流程。

归档使条目退出自动召回；直接删除会移除该条记忆及其检索投影。它们不等同于清空原会话历史，也不撤销曾经依据该信息完成的外部操作。

### 理解后台历史提炼 {/* #理解后台历史提炼 */}

上下文压缩成功后，或会话持续空闲后，系统可把已封口的原始历史交给后台提炼。提炼读取的是原消息片段，不是把上下文摘要反向当成事实来源。

- 只接受有证据的稳定偏好、用户已接受决策、可验证事实和少量长期事件。
- 问句、假设、未接受建议、临时进度、秘密和缺少有效证据的候选会被拒绝。
- 偏好和决策需要直接用户证据；决策还必须有用户已接受的依据。
- 后台内容不具有长期指令权限，不能自动变成规则或禁止项，也不能仅凭冲突候选改写、归档或替代已有事实。
- 后台提炼和检索可能延迟；没有召回到某条信息，不等于从未说过，也不证明已成功保存。

### 区分四种连续性信息 {/* #区分四种连续性信息 */}

| 信息 | 作用范围 | 应如何使用 |
| --- | --- | --- |
| 会话历史 | 当前会话的原始沟通过程 | 核对当时说了什么 |
| 上下文摘要 | 当前会话继续执行 | 保存目标、约束、进度和待解决问题 |
| 工作记录 | 当前会话的主题记录、修订和增量 | 核对阶段证据与接续状态 |
| 长期记忆 | 同一用户的多个会话 | 复用符合准入要求的稳定背景 |

## 使用边界 {/* #使用边界 */}

| 信息 | 是否适合作为长期记忆 |
| --- | --- |
| 稳定偏好、已确认决策和长期边界 | 适合，并应明确要求记住 |
| 临时任务、当前进度和一次性文件路径 | 不适合 |
| 密码、Token、私钥等秘密 | 不应保存 |
| 助手自己的建议或未经确认的推断 | 不应保存 |
| 实时价格、新闻和外部系统当前状态 | 应重新查询来源 |
| 其他用户或无权访问的数据 | 不可读取或保存 |

## 隐私与准确性 {/* #隐私与准确性 */}

- 长期记忆按当前用户边界读取，不会因为知道其他会话或用户的名称就自动获得访问权。
- 记忆只提供背景连续性，不证明某项操作已经执行，也不扩大当前 Session 的职责和权限。
- 低置信度、过期、冲突或已被替代的记忆不能作为已确认事实直接使用。
- 记忆中保留原始来源时，依赖该记忆的回答应继续保留可核对的来源链接。
