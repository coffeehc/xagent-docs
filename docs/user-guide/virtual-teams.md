# 虚拟团队：经理、成员与归档

版本范围：Server `v0.1.0`，依据[正式发布说明](https://github.com/coffeehc/xagent-releases/releases/tag/v0.1.0)。手册其他位置的旧截图不展示本版界面。

## 开始一个团队 {/* #start-team */}

1. 创建虚拟团队，初始化专用经理。
2. 向经理说明目标、材料、边界和验收标准；按需复用岗位模板，并查看成员会话树。
3. 跟进成员聊天和任务结果；需要澄清或决策时，使用所有者指导入口。经理可以委托其他经理，但委托成功不等于任务完成。
4. 到共享业务目录核对成果，查看文件引用与预览，再按验收标准确认结果。

团队资料共享不等于授权访问其他用户或外部系统；原有账号权限和审批规则仍适用。WorkGroup 编排配置、会话执行和远端 A2A 是不同层次。

## 归档、恢复与继续执行 {/* #archive-restore */}

解散团队会整体归档并保留成员关系，归档资料可只读查看。恢复团队和继续执行有明确入口，不应把恢复当作自动续跑；继续前先核对原目标和未完成动作。

长期未使用的会话也可自动归档。会话从活跃列表消失时，按普通、团队、插件与已归档导航范围查找。发布说明没有给出统一闲置时长，请核对当前部署，不要假定固定阈值。

## 升级后验证 {/* #verify-upgrade */}

用非敏感测试材料依次检查创建团队、经理初始化、成员任务、共享产物、归档只读查看、恢复和明确续跑。以自己的部署验证为准；发布时的构建与完整性检查不等于完整业务验收。
