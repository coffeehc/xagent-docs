# 文件外链分享

从 `v0.0.19.beta` 起，用户可以分享自己有权访问的受管文件。**文件外链默认关闭**；先由管理员在“存储管理 > 文件分享”启用策略。外链面向无需登录的访客，请勿分享不应公开的材料。

## 管理员开启

管理员在“存储管理 > 文件分享”选择分享范围：关闭、仅 xAgent 生成的产物，或所有用户受管文件。还可设置默认及最长有效期、是否允许原文件下载、公开 Base URL。保存后再由用户创建链接；策略收窄可能使已有链接失效。公开访问需要 HTTPS 反向代理并确保访问域名能到达服务，不要把内部地址直接作为外链。

## 创建与管理

1. 在文件预览、会话文件或“工作台 > 工作区文件”中找到文件，选择分享操作。
2. 选择有效期，并根据管理员策略决定是否允许下载原文件。不能创建永久链接。
3. 创建后复制链接，先用无登录状态的浏览器验证预览，再发给需要的人。
4. 在“工作台 > 文件分享”按文件查看链接、访问与下载汇总，打开详情查看各链接和访问记录；不再使用时立即撤销链接。

访客打开链接看到动态水印预览。只有为该链接开启原文件下载、且管理员允许下载时，访客才可以获取原文件；原文件本身不附加预览水印。到期、撤销、管理员策略阻断或文件不可用时，链接停止提供访问。

## 安全边界

- 公开链接是匿名访问能力；持有链接的人可能继续转发，不要将其视为登录授权。
- 水印与访问记录便于追踪，不等于阻止拍照或外部传播。
- 分享范围与下载权限由管理员设上限，单个链接只能在上限内选择。
- 分享及下载统计和逐次访问记录可在“文件分享”详情中核对。
